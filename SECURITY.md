# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use the affected repository's **Security** tab to submit a private vulnerability report. Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. If private reporting is unavailable, contact an organization owner through GitHub without disclosing exploit details publicly.

We will acknowledge a report as soon as practical, investigate it, and coordinate disclosure and remediation with the reporter. Please allow time for a fix to reach supported users before publishing details.

## Supported versions

Until a repository publishes a project-specific support table, only its latest released version receives security updates.
